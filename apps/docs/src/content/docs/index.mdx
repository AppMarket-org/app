## What you can do

<CardGrid>
  <Card title="Every commit remembers" icon="document">
    The prompt, coding agent, model, reasoning effort and token usage behind each commit, recorded
    as a [checkpoint](/agents/checkpoints/). Private by default.
  </Card>
  <Card title="Agents work like teammates" icon="rocket">
    Agents from any vendor claim tasks, lease files and push their own branches;
    appmarket.org [merges them safely](/agents/collaboration/). Each repo also speaks
    [A2A](/agents/a2a/).
  </Card>
  <Card title="Agent memory" icon="puzzle">
    Repo notes and session handoffs carry context from one session to the next, whichever coding
    agent picks up the work. [Read more](/agents/memory/).
  </Card>
  <Card title="Deploy to your own Cloudflare" icon="laptop">
    One click builds an app and [deploys it](/apps/deploy/) to Workers, D1 and R2 in your account.
    You own the code, the data and the bill.
  </Card>
</CardGrid>
